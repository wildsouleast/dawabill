# DawaBill — free medical store bill / pharmacy GST invoice generator

Static site (no server). Pages are generated by `build.py` into `site/`; GitHub Pages serves the `docs/` copy.
- Change `BASE` (or set `DAWABILL_BASE`) when a custom domain is added, run `python3 build.py`, then copy `site/` to `docs/`.
- Tests: `node --test`
- Ad slots: search for `AD SLOT` in the HTML.
